# streaming-service-analysis
MySQL project for analyzing users, content views and revenue in a streaming service
# Streaming Service Analysis

## Описание проекта

SQL-проект по анализу пользовательской активности и ключевых показателей стримингового сервиса.

## Инструменты

- MySQL
- SQL

## Задачи проекта

- Анализ регистраций пользователей
- Анализ распределения пользователей по странам
- Анализ просмотров контента
- Расчет средней продолжительности просмотра
- Определение количества уникальных зрителей
- Анализ наиболее популярных фильмов
- Расчет месячной выручки
- Анализ последней активности пользователей

## Использованные SQL-инструменты

- JOIN
- LEFT JOIN
- GROUP BY
- COUNT
- COUNT DISTINCT
- SUM
- AVG
- ORDER BY
- Работа с датами
- Агрегатные функции

## Результат

Проект демонстрирует использование MySQL для анализа пользовательской активности, контента и финансовых показателей стримингового сервиса.
